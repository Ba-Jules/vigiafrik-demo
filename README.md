# VigiAfrik — démo

**Essayer : https://ba-jules.github.io/vigiafrik-demo/**

VigiAfrik permet à la diaspora de piloter à distance un chantier au Sénégal : étapes validées sur photos, caisse du chantier, reste à payer à chaque artisan, achats comparés aux prix habituels, messages vocaux, mode chantier hors ligne. Montants en FCFA, avec l'équivalent en euros.

Cette page est une **version de démonstration** : données fictives, paiements simulés, et rien ne quitte votre navigateur. Sur l'écran de connexion, choisissez l'un des trois comptes (propriétaire, gérant du chantier, famille). Le bouton « Réinitialiser la démo » remet tout à zéro.

Ce dépôt ne contient que le site compilé. Le code source est dans un dépôt privé.
